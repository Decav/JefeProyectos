# Frontend React · Entrypoint Claude Code

Este archivo existe únicamente para que Claude Code cargue automáticamente las reglas del frontend. La fuente de verdad está en `AGENTS.md`.

**Leer ahora: [AGENTS.md](AGENTS.md).**
